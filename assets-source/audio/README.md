# Audio sources (P5-T8)

Music and SFX for Clockwork Spire. Runtime files are in `public/assets/audio/`, the code in `src/audio/`.

## Layout

| Path | What |
| --- | --- |
| `sfx/prompts.json` | Sound-effect specs, including source descriptions, duration, class, loop flags and the synthesis settings for the three original bell tones. |
| `sfx/raw/*.mp3` | Immutable ElevenLabs outputs, 44.1 kHz stereo MP3 (the Starter plan cannot request PCM). Never edited. |
| `sfx/procedural/*.wav` | Deterministic local sources generated by `build_audio.py` for original clockwork bell strikes. |
| `sfx/foley/` | Immutable high-quality CC0 recording previews. [sources.json](sfx/foley/sources.json) records the sound, author, license and download hash. Cue edits are listed under `foley` in [prompts.json](sfx/prompts.json). |
| `sfx/generation-log.json` | One entry per request: payload, response headers (including `character-cost`), sha256, size, time. |
| `sfx/meter-before.txt`, `meter-after.txt` | `GET /v1/user/subscription` credit counters around the batch. |
| `music/SUNO-HANDOFF.md` | Suno prompts, settings and loop preparation for all eleven music cues (D12). The final music is owner-generated in Suno. |
| `music/*.wav` | The eleven immutable Suno WAVs selected and supplied by Paul on November 23, 2026. |
| `music/generation-log.json` | Suno song IDs and creation times from embedded metadata, received filenames, source hashes and approval evidence. |
| `music/loops.json` | Onset-aligned Suno loop points, crossfade durations, and stereo-width adjustments for mono playback. |
| `music/placeholder/` | Earlier placeholder music: all eleven cues from Stable Audio 3 medium, run locally, with the Suno prompts. `generation-log.json` holds every request, seed and timing, and `loops.json` the loop points. | `music/cues.json` | The music cue list in first-heard order: id, loop flag, source and runtime paths, Style prompt and Suno settings. The build and the audition page read it; a test keeps it in step with `src/audio/cues.ts`. |
| `derived/*.wav` | Lossless 48 kHz float intermediates, one per cue, rebuilt by the script. |
| `provenance.json` | Machine-readable record: rights, approvals, prompts, per-cue source and runtime hashes and processing steps. Written by the build. |

## Build

`uv run --no-project --with numpy==2.5.5 python -I scripts/assets/build_audio.py` with ffmpeg 9.0.2 and libopus on PATH. It is deterministic: two consecutive builds gave identical Ogg hashes and an identical `report.json`. `scripts/assets/generate_sfx.py` made the generations and skips any cue whose raw file exists; `--retry <id>` is the only way to spend a second take.

Per cue: decode to 48 kHz float, trim silence more than 50 dB under the clip peak (5 ms head, 10 ms tail margin), 2 ms fade in and a raised-cosine fade out, fold positional cues to mono with `0.5*L + 0.5*R`, apply one linear gain toward the target, encode, then **measure the decoded Opus file**. The gain is capped so the decoded true peak stays at or under -1.0 dBTP, and re-encoded with less gain if the lossy encode overshoots. `loudnorm` is not used, because it silently stops honouring its targets past the linear limit.

## Format decision

Ogg Opus at 48 kHz. Quest Browser is Chromium and decodes Ogg Opus, as does desktop Chrome and Firefox, so no AAC fallback is shipped. Opus gives the smallest files at transparent quality for short cues (the 20 SFX total 283 KB) and has no encoder-delay problem: the Ogg container carries exact sample counts, which keeps music loops gapless. Positional cues are mono 64 kbps because a `PannerNode` needs a mono input, UI cues and stingers are stereo 96 kbps, music is stereo 128 kbps. Safari support for Ogg Opus is not a target of this slice.

## Targets and results

SFX -16 LUFS integrated and music -18 LUFS, true peak at most -1.0 dBTP, tolerance 1 LU. These were proposed in the task and are new project values. Measured results per cue are in `public/assets/audio/report.json`. Twelve SFX miss -16 LUFS because their peaks sit at full scale while the body is quiet (crest factor), so the true-peak ceiling stops the gain. They are mastered to the ceiling and flagged `deviation` with `limited_by_true_peak`. Nothing was limited or compressed to hide that. Integrated loudness of clips under one second is a gated measurement over a single 400 ms block, so the report also carries the momentary maximum. Measurements pad the clip with digital silence to 1.2 s, which the absolute gate ignores.

The Suno soundtrack uses nine loop bodies cut to the documented runtime lengths and two one-shots with their natural endings. The loop selections use measured onsets and similarity near each join. The source WAVs preserve the complete takes. The game decodes music on demand. All eleven mastered tracks measure -18.0 LUFS. The highest decoded true peak is -4.7 dBTP. The nine loops pass wrap, level and dropout checks, and all eleven cues pass the stereo-to-mono cancellation check. Paul approved all eleven mastered music cues on Quest on November 23, 2026.

## Quest listening review

The November 23 Quest review and follow-up confirmation approved all 11 Suno cues and 63 sound effects. Five effects were rejected. The [cue-by-cue record](owner-review.json) binds the verdicts to the exact Opus files heard on build `9666f75`.

Rejected effects were `prism-annex-open`, `dungeon-torch-crackle`, `dungeon-chain-wind`, `dungeon-scarab-scrape`, and `armory-awaken`.

The five rejected takes were replaced using recorded Foley. Glass-like contacts and a sliding metal guide give the Prism Annex gate a distinct opening sound. The dungeon torch loop uses real burning wood. Dragged iron links and a ratchet catch announce the Bailiff, while a stone scrape and three light metal contacts announce the Scarab. A ratchet and two real armor contacts mark the mannequin waking. The premix controls isolated peaks on four effects before linear mastering. Paul approved all five replacement takes on November 23, 2026. The cue-by-cue record retains the rejected originals and lists the approved replacement hashes. The current soundtrack and effects have 11 music approvals and 68 SFX approvals. The Prism Annex opening measures -18.0 LUFS against the -16 LUFS goal, with -1.1 dBTP true peak.
